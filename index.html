Omarchy Laptop Backup

A personal backup utility operated by Reynold Lariza for his own Linux laptop. It uses Restic to encrypt versioned backups locally and Rclone to store them in his Google Drive account.

Google authorization allows the utility to create and manage its backup files and download them for recovery. It requests the drive.file permission, which limits access to files created by or explicitly shared with this application.

This application is for its owner's personal use and is not a public backup service.
